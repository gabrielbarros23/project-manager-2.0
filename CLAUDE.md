Esse projeto é um dos meus principais no meu portfólio, é uma aplicação simples, mas com fundamentos de autenticação e autorização bem desenvolvidos. Nele, o usuário pode criar uma conta e, com essa conta, ele consegue criar projetos; consequentemente, ele pode editar, deletar e até chamar usuários para esse projeto. Depois, ele pode criar tarefas para esse projeto, conseguindo atribuir usuários a essa tarefa e conseguindo editar os dados dessa tarefa, como data de vencimento e status. Também o dono do projeto pode colocar cargos em seus participantes e mais funcionalidades que levam em consideração autenticação e autorização. A maior parte do meu empenho nesse projeto foi no back-end, mas, após dar uma olhada nas vagas atualmente no LinkedIn, percebi muitas candidaturas para empresas focadas em full-stack. Dado esse fato, resolvi que essa aplicação também pode ter um front-end para se tornar uma aplicação full-stack. É aqui que eu vou precisar da sua ajuda; gostaria que você me ajudasse a criar uma interface para o meu back-end.
